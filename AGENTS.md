# Agent Guidelines & Repository Rules

## Git Workflow Rules
- **STRIKTES VERBOT:** Niemals direkt auf den Branch `main` (oder `master`) committen oder pushen.
- **Entwicklungs-Branch:** Alle Änderungen, Commits und Pushes erfolgen ausschließlich auf dem Branch `paper-l` (oder dedizierten Feature-Branches).
- **Merges nach main:** Merges oder Übertragungen nach `main` dürfen niemals automatisiert vom Agenten durchgeführt werden, sondern erfolgen ausschließlich durch den Nutzer (z. B. via Pull Request).
